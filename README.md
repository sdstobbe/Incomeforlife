# Income For Life

Interactive, responsive Q&A site for **BG Wealth Sharing** and **DSJ Exchange**.

## Run locally

```bash
cd "Income For Life"
npm install
npm run dev
```

Then open the URL shown (e.g. http://localhost:5173).

## Build for production

```bash
npm run build
```

Output is in the `dist` folder.

## Project structure

- **src/App.jsx** – Main app and expandable Q&A blocks
- **src/qaData.js** – All Q&A content, organized by section
- **src/index.css** – Layout and responsive styles

Edit `src/qaData.js` to change or add questions and answers.
